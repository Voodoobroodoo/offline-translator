# Офлайн-переводчик

Нейросетевой переводчик для Windows, работающий **полностью без интернета**.
Интерфейс — **CustomTkinter** (скруглённые кнопки, современный вид), движок —
[Argos Translate](https://www.argos-translate.com/) (OpenNMT), модели хранятся локально.

## Запуск

- **`Переводчик.exe`** — двойной клик (первый запуск ~10–20 c, SmartScreen: «Подробнее → Выполнить в любом случае»).
- `Переводчик.bat` — запуск из исходников (нужен Python + `argostranslate` + `pystray`).

## Горячие клавиши (работают в любой программе)

| Клавиша | Действие |
|---|---|
| **Ctrl+Alt+T** (по умолч.) | перевести текст из буфера обмена |
| **Ctrl+Alt+S** (по умолч.) | перевести **выделенный** текст — приложение само нажмёт Ctrl+C в активной программе |

Результат в обоих случаях: всплывашка у курсора + перевод уже в буфере (Ctrl+V).
Клавиши меняются внизу окна, выбор хранится в `settings.ini`.

## Трей

Закрытие окна не завершает приложение — оно сворачивается в трей и клавиши продолжают
работать. Меню значка в трее: «Показать», «Перевести выделенное», «Перевести из буфера»,
«Выход» (полный выход — только там).

## Главное окно

- **Пара** — языковая пара (EN ⇄ RU и любые установленные), **Направление** — авто/прямое/обратное.
- Автоопределение языка: по алфавиту и частым словам (ru/uk различаются, для латиницы —
  стоп-слова en, de, fr, es, it, pt, nl, pl, tr).
- `Ctrl+Enter` — перевести, «⇄» — обменять тексты, «Копировать» — перевод в буфер.
- **Языки…** — диалог установки дополнительных пар: «Показать доступные» (нужен интернет,
  ~30–100 МБ на пару) → отметить → «Скачать отмеченные». Дальше пара работает офлайн.

## Темы

Список «Тема:» справа вверху. Простые: Светлая, Тёмная, Бумага (Georgia), Контраст,
Океан, «Своя» (редактор цветов/шрифта — сохраняется в `settings.ini`).
Креативные: **Неон** (киберпанк), **Терминал** (зелёный моноширинный), **Ретро-95**
(Tahoma, минимум скруглений), **Космос** (звёздное небо-обои) и **Закат** (градиентные
обои). Превью — `preview_*.png`.

Прочие украшения: логотип, сегментный переключатель направления (Авто / EN → RU /
RU → EN), скруглённые карточки текстовых полей; у каждой темы свой радиус скруглений.

## Однократность запуска

Копий приложения можно наоткрывать несколько, но глобальные клавиши достанутся
только первой — остальные будут «молчать». Лишние копии видны в трее/диспетчере
задач как `Переводчик.exe` — закройте лишние.

## Установка (уже выполнена)

Интернет нужен был только один раз:
1. `python -m pip install argostranslate pystray customtkinter pyinstaller`
2. `python install_models.py` — модели EN→RU и RU→EN в
   `C:\Users\<пользователь>\.local\share\argos-translate\packages` + кэш MiniSBD.

## Сборка exe

`build_exe.bat` → `dist\OfflineTranslator.exe` (переименовать в `Переводчик.exe`).
Проверка: `Переводчик.exe --test` → `selftest_result.txt` (клавиши, трей-библиотека,
автоопределение, перевод). Хитрость: `stanza.py`-заглушка + `ARGOS_CHUNK_TYPE=MINISBD`
позволяют не тащить torch (~2 ГБ → exe ~62 МБ).
