# Офлайн-переводчик для Android

Нативный Android-эквивалент Windows-версии. **Это не порт Python-кода** — Windows-стек
(tkinter, Win32-хоткеи, ctranslate2) на Android недоступен физически. Здесь движок —
**ML Kit Translation** (офлайн-перевод Google): модели EN⇄RU скачиваются один раз
(~30 МБ каждая), дальше перевод работает полностью без интернета.

## Что уже есть (v1.0.0-эквивалент)

- Перевод EN → RU и RU → EN офлайн (после разовой загрузки моделей).
- Кнопка «Модели» — проверить/дозагрузить пакеты (нужен интернет, один раз).
- Копирование результата в буфер обмена.
- Тёмная/светлая тема следует системной.

## Как собрать APK

Вариант 1 — **GitHub Actions (Android SDK не нужен):**
1. Заведите репозиторий на GitHub, положите туда папку `android` в корень.
2. Скопируйте `android/ci/build-apk.yml` в `.github/workflows/build-apk.yml`.
3. Вкладка Actions → «Build APK» → Run workflow → скачайте артефакт `app-debug.apk`.

Debug-APK ставится на любой телефон (разрешите «установка из неизвестных источников»).

Вариант 2 — Android Studio: File → Open → папка `android` → Run.

## Нюансы

- На устройствах **без сервисов Google (Huawei без GMS)** ML Kit не заведётся —
  там нужен аналог HMS ML Kit или он-девайс модель через ONNX Runtime Mobile.
- F-Droid такую сборку не примет: ML Kit — проприетарный компонент.
