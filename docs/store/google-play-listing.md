# Листинг для Google Play (заготовка — собранная Windows- и Android-версия)

## Название (до 30 символов)
Офлайн-переводчик EN⇄RU

## Краткое описание (до 80 символов)
Нейросетевой перевод английский⇄русский без интернета. Быстро, приватно, локально.

## Полное описание
Использовать текст из rustore-listing.md (совпадает по смыслу).

## Анкета «Безопасность данных» (Data safety)
- Собирает ли приложение персональные данные? Нет
- Передаёт ли данные третьим лицам? Нет
- Шифрование данных в передаче: неприменимо (данные не передаются)
- Удаление по запросу: неприменимо (данные не собираются)
- ВАЖНО: заявить, что ML Kit Translation работает на устройстве (on-device),
  тексты не отправляются на серверы Google после загрузки моделей.

## Возрастной рейтинг
Вопросник: нет насилия/азартных игр/покупок → «Для всех» (Everyone / 3+).

## Формат
Google Play принимает **AAB** (не APK): `gradle -p android bundleRelease`
плюс release-подпись (keystore). Для внутреннего тестирования достаточно debug/AAB
с upload-ключом, который Play сгенерирует.

## Целевой API
targetSdk 34+ (в проекте уже 34).

## Особенность для РФ
Регистрация нового аккаунта разработчика из РФ практически закрыта — нужен аккаунт
другой юрисдикции и карта не из РФ (подробности в docs/publishing.md).
