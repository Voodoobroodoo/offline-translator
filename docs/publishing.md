# Куда выкладывать: расклад по площадкам

Состояние на сентябрь 2026. Условия (комиссии, регистрация, модерация) меняются —
перед подачей проверьте актуальные требования на сайтах площадок.

## Что подавать куда

| Продукт | Куда идти |
|---|---|
| Windows exe/установщик | GitHub Releases, Microsoft Store, свой сайт |
| Android APK/AAB | RuStore, Google Play, Huawei AppGallery, Xiaomi GetApps, Samsung Galaxy Store, NashStore, GitHub Releases |

## Windows

### GitHub Releases (рекомендую первым шагом)
- Бесплатно, без модерации, файлы до 2 ГБ на релиз.
- Заливаете `Переводчик-Setup-1.0.0.exe`, `Переводчик-Портативный-1.0.0.zip` и RELEASE_NOTES.
- Ссылку можно давать кому угодно; SmartScreen будет предупреждать (exe не подписан).
- Лечится код-подписью: сертификат подписи кода ≈ $70–400/год (или бесплатно через
  Azure Trusted Signing ~$10/мес) — предупреждения исчезают.

### Microsoft Store
- Регистрация разработчика: $19 единоразово (индивидуально).
- Нужен MSIX-пакет: наш onefile-exe оборачивается в MSIX (MSIX Packaging Tool).
- Модерация 1–7 дней. Плюс: магазин сам раздаёт обновления, нет SmartScreen-страха.

## Android

### RuStore (рекомендую для РФ первым шагом)
- Регистрация разработчика через **Госуслуги**; для физлиц бесплатно.
- Формат: APK или AAB. Модерация обычно 1–3 дня.
- Политика приватности обязательна. Комиссии/условия продаж — проверить актуальные.
- Наш APK (ML Kit) проходит: Google-компонент встроен в APK, пользователю RuStore
  сервисы Google не нужны — но на устройствах без GMS перевод не заработает (см. ниже).

### Google Play
- Регистрация: **$25 единоразово**, нужна идентификация (документ, адрес, банковские
  реквизиты). ВАЖНО: Google с 2022 года практически не регистрирует новые аккаунты
  разработчиков из РФ — нужен аккаунт другой юрисдикции и способ оплаты не из РФ.
- Формат: **AAB** (не APK!) — собирается той же Gradle-командой `bundleRelease`,
  потребуется release-keystore подпись.
- Обязательно: политика приватности (URL), анкета «Безопасность данных»
  (у нас: данные не собираются; ML Kit работает на устройстве), возрастной рейтинг,
  target API 34+. Модерация 1–7 дней после верификации аккаунта.

### Huawei AppGallery
- Регистрация бесплатна, модерация 1–3 дня, принимает APK.
- Нюанс: на телефонах Huawei без сервисов Google наш ML Kit-перевод работать не будет.
  Чтобы покрыть Huawei, нужен переводной движок HMS ML Kit (у Huawei есть аналог) или
  ONNX Runtime Mobile — заложить отдельную сборку.

### Xiaomi GetApps / Samsung Galaxy Store / NashStore
- Региональные магазины, регистрация бесплатная, модерация 1–5 дней, формат APK.
- Имеют смысл после RuStore/Play как дополнительный охват; аудитория меньше.

### Прямая раздача APK (GitHub Releases / сайт)
- Бесплатно, без модерации. Пользователь ставит вручную, разрешив «неизвестные
  источники». Удобно для бета-тестеров.

### F-Droid — НЕ подходит
- F-Droid требует только свободные зависимости; ML Kit проприетарен. Обходной путь —
  отдельная сборка с ONNX Runtime Mobile (большая работа).

## Обязательные документы для любого стора

1. **Политика приватности** — публичная страница с текстом. Заготовка для нас:
   «Приложение работает полностью на устройстве. Не собирает, не хранит и не передаёт
   персональные данные, историю переводов и телеметрию. Интернет используется только
   для разовой загрузки моделей перевода по явному действию пользователя.»
2. **Иконка** 512×512 (PNG) + скриншоты 2–8 шт (телефон). У нас уже есть тематические
   превью — скриншоты делаются из приложения за 5 минут.
3. **Короткое описание** (до 80 знаков) и **полное описание**.
4. Возрастной рейтинг — вопросник (наш случай: «для всех», 3+/Everyone).

## Порядок действий (мой совет)

1. GitHub Releases (Windows + APK) — сегодня, ноль затрат, проверка интереса.

4. Huawei/GetApps/Galaxy — опционально, послеthought про HMS-сборку.
